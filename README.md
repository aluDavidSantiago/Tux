# Tux 🐧

**Tux** es una red social minimalista y elegante diseñada para romper la rutina diaria mediante la sugerencia de actividades aleatorias, económicas y de bajo esfuerzo físico. Todo integrado en una experiencia visual premium, multimedia de alta calidad y la compañía de nuestra mascota oficial.

## 🚀 Características Principales
- **Planes Aleatorios:** Sugerencias casuales y accesibles para transformar tu día a día sin esfuerzo.
- **Filtros Personalizables:** Sincronización en la nube de tus preferencias (presupuesto, nivel de actividad y categorías).
- **Experiencia Multimedia Premium:** Publicación y visualización de contenido sin compresión, con soporte para HDR y Dolby Atmos.
- **Feed Social:** Interacciones fluídas, formatos estilo carrusel y vídeos cortos (*Shorts*).
- **Diseño Adaptable:** Interfaz dinámica con soporte para modo claro, modo oscuro y ajuste automático según el sistema.

## 🛠️ Stack Técnico
- **Frontend:** HTML5, CSS3, JavaScript.
- **Backend / Servicios:** Firebase (Autenticación, Base de datos, Storage).
- **Control de Versiones:** Git & GitHub.
